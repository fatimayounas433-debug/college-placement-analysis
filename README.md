This project analyzes college student placement data using SQL. The goal is to explore how factors like CGPA, academic performance, internships, communication skills, and projects influence placement outcomes.

🎯 Objectives

Understand the relationship between student performance and placement results.

Identify trends in CGPA, internships, and extracurricular activities.

Practice SQL skills such as filtering, grouping, joins, and subqueries.

📂 Dataset

The dataset includes columns such as:

College_ID

IQ

Prev_Sem_Result

CGPA

Academic_Performance

Internship_Experience

Extra_Curricular_Score

Communication_Skills

Projects_Completed

Placement (Yes/No)

🛠️ Tech Stack

SQL (MySQL / SQL Server / PostgreSQL)



Excel (for review & validation)

GitHub (for version control & sharing)
